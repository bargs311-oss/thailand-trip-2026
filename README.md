# 🇯🇵 JapanTrip - אפליקציית ניהול ותכנון טיול ליפן (PWA + Realtime)

> 🌐 **כתובת האפליקציה החיה:** [https://rushing-nebula-spcxzsj.vercel.app](https://rushing-nebula-spcxzsj.vercel.app)  
> 📱 **PWA Standalone:** מותאם מלא למסך הבית של iOS ו-Android עם תמיכה מלאה במצב אופליין (Offline-first).

אפליקציית Web & PWA מודרנית שנבנתה במיוחד עבור מסע האחים ליפן. האפליקציה תוכננה לשימוש מהיר ביד אחת ברחובות טוקיו, שיבויה וקיוטו, עם תמיכה מלאה במצב אופליין ברכבות תחתיות וסנכרון Realtime בין שני האחים דרך Supabase.

---

## 🌟 פיצ'רים מרכזיים

### 1. שתי תצוגות ראשיות (Switch מהיר ב-Header)
* **⚡ מצב שטח (Today's Dashboard):**
  * **כרטיס היעד הבא:** הצגת האטרקציה הקרובה, הזמן המשוער, הנחיות מיוחדות, ועלות.
  * **כפתור ניווט ישיר ל-Google Maps:** לחיצה אחת פותחת את המסלול ב-Google Maps.
  * **כפתור פתיחת כרטיס:** הצגת שובר דיגיטלי, קוד QR, מס' הזמנה והנחיות כניסה.
  * **סמן כהושלם (Done):** מעבר אוטומטי ליעד הבא ברשימה.
  * **כרטיס מלון עם כתובת ביפנית:** הצגת שם המלון והכתובת בקנג'י גדול לנהגי מוניות, כולל מס' טלפון להזנה ב-Navi של הרכב.
  * **ממיר ין לשקל מהיר:** פופ-אפ מהיר עם NumPad מותאם למובייל וכפתורי קיצור לסכומים נפוצים (אוניגירי, ראמן, שינקנסן).

* **🗺️ מצב תכנון (Planning Mode):**
  * חלוקה לפי ימים וערים (טוקיו, האקונה, קיוטו, אוסקה).
  * רשימת נקודות עניין, אטרקציות ושעות מתוכננות.
  * סימון ביצוע (Checkboxes) המסתנכרן בזמן אמת.
  * הוספה, עריכה ומחיקה של יעדים כולל קישורי כרטיסים והערות סודיות.

---

### 2. אינטגרציית Supabase וסנכרון בזמן אמת (Realtime)
* **קובץ סכמה מלא:** `supabase/schema.sql` כולל טבלאות:
  * `trips`
  * `trip_days`
  * `itinerary_items`
  * `expenses`
  * הגדרת פוליסות RLS והפעלת `supabase_realtime` לשיתוף מיידי.
* **Custom Hook מתקדם:** `src/hooks/useItineraryRealtime.ts` מאזין לערוצי Realtime (`postgres_changes`) ומעדכן את הממשק באופן מיידי כשאחד האחים מסמן יעד או מוסיף מקום.
* **Fallback מקומי מלא (Offline First):** עובד מיד ללא כל הגדרה ראשונית באמצעות `LocalStorage` ונתוני Mock עשירים ואותנטיים.

---

### 3. PWA ותמיכה באופליין
* קובץ `manifest.json` המאפשר התקנה כאפליקציה במסך הבית (Add to Home Screen) ב-iOS וב-Android.
* `sw.js` (Service Worker) ששומר את כל קובצי הממשק לצפייה מהירה גם במנהרות ובמקומות ללא קליטה.

## 🔑 חיבור לפרויקט Supabase שלכם

1. צרו פרויקט בחינם ב-[supabase.com](https://supabase.com).
2. היכנסו ל-**SQL Editor** והדביקו את התוכן של `supabase/schema.sql`.
3. באפליקציה, לחצו על כפתור הסנכרון ב-Header (אייקון ה-Wifi) והזינו את ה-**Project URL** וה-**Anon Key**.
4. מעתה, כל שינוי שתבצעו יסונכרן בזמן אמת בין שני המכשירים!
